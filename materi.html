01 / MATERI PEMBELAJARAN

Mengenal Komputasi Awan.

Memahami cara layanan komputasi melalui internet membantu pengguna menyimpan data, menjalankan aplikasi, dan mengelola infrastruktur.

DASAR

Apa itu komputasi awan?

Komputasi awan (cloud computing) adalah model penyediaan sumber daya komputasi seperti server, penyimpanan, basis data, jaringan, dan perangkat lunak melalui jaringan internet sesuai kebutuhan. Pengguna dapat memanfaatkan layanan tersebut tanpa harus memiliki dan mengelola seluruh infrastruktur fisik sendiri.

Contoh penggunaan sehari-hari antara lain menyimpan berkas secara daring, menggunakan aplikasi melalui browser, serta menjalankan website pada layanan hosting.

MODEL LAYANAN

Tiga model utama cloud.

SSoftware

SaaS

Software as a Service

Perangkat lunak siap digunakan melalui internet. Pengguna cukup memakai aplikasi, sementara penyedia mengelola infrastruktur dan pemeliharaannya.

ContohGoogle Drive, Gmail, Microsoft 365
PPlatform

PaaS

Platform as a Service

Platform untuk mengembangkan, menguji, dan menjalankan aplikasi tanpa perlu mengelola server dan sistem operasi secara langsung.

ContohGoogle App Engine, Heroku, Azure App Service
IInfrastructure

IaaS

Infrastructure as a Service

Penyediaan sumber daya infrastruktur virtual seperti mesin komputasi, jaringan, dan penyimpanan. Pengguna memiliki kendali lebih besar atas sistem yang digunakan.

ContohAmazon EC2, Google Compute Engine, Azure VM
PERTIMBANGAN

Manfaat dan risiko.

Manfaat

  • Fleksibel: sumber daya dapat disesuaikan dengan kebutuhan.
  • Efisien: mengurangi kebutuhan membeli dan merawat server sendiri.
  • Akses mudah: layanan dapat diakses dari berbagai lokasi selama tersedia internet.
  • Skalabilitas: kapasitas dapat ditingkatkan ketika kebutuhan bertambah.

Risiko

  • Ketergantungan internet: akses dapat terganggu ketika koneksi bermasalah.
  • Privasi dan keamanan: data perlu dilindungi dengan pengaturan akses yang tepat.
  • Ketergantungan penyedia: perubahan layanan atau kebijakan penyedia dapat berdampak pada pengguna.
  • Biaya: penggunaan sumber daya tertentu dapat menimbulkan biaya berkelanjutan.
