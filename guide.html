03 / PANDUAN PRAKTIK

Publikasikan website dengan GitHub Pages.

Ikuti panduan berikut untuk mengunggah website statis ke GitHub dan membuatnya dapat diakses secara online tanpa mengelola server sendiri.

⏱ Sekitar 10–20 menit⌘ HTML, CSS, dan JavaScript☁ Hosting website statis
Sebelum memulai

Siapkan akun GitHub dan folder website yang sudah berisi file HTML, CSS, JavaScript, serta aset pendukung seperti gambar. Pastikan halaman utama bernama index.html.

01
LANGKAH PERTAMA

Buat repository di GitHub

Masuk ke GitHub, kemudian login ke akun kamu. Klik tombol New repository untuk membuat tempat penyimpanan file website.

  • Isi nama repository, misalnya website-komputasi-awan.
  • Pilih Public agar repository dapat digunakan dengan GitHub Free.
  • Klik Create repository.

Untuk website proyek, nama repository tidak harus menggunakan format username.github.io. Format tersebut digunakan untuk website utama akun atau organisasi.

02
UNGGAH FILE WEBSITE

Upload seluruh file proyek

Buka repository yang baru dibuat, pilih Add file → Upload files, lalu unggah seluruh isi folder website.

  • Pastikan index.html berada di direktori utama repository.
  • Folder seperti assets, css, js, dan images tetap berada pada susunan folder yang benar.
  • Setelah proses unggah selesai, isi pesan commit, misalnya Upload website awal, lalu klik Commit changes.
Contoh susunan file
website-komputasi-awan/
├── index.html
├── materi.html
├── portofolio.html
├── guide.html
└── assets/
    ├── css/
    ├── js/
    └── images/
03
KONFIGURASI DEPLOYMENT

Aktifkan GitHub Pages

Di halaman repository, buka menu Settings. Pada bagian sidebar Code and automation, pilih Pages.

Pada bagian Build and deployment, atur konfigurasi berikut:

SourceDeploy from a branch
Branchmain
Folder/(root)

Setelah itu, klik Save. GitHub Pages akan mengambil file website dari branch main dan direktori utama repository.

04
CEK HASIL PUBLIKASI

Buka website yang sudah online

Kembali ke menu Settings → Pages. Setelah proses deployment berhasil, GitHub akan menampilkan alamat website dan tombol Visit site.

Untuk repository proyek, alamat umumnya menggunakan format:

https://username.github.io/nama-repository/

Ganti username dan nama-repository dengan nama akun serta repository milikmu. Jika website belum tampil, tunggu beberapa menit dan periksa status proses pada tab Actions.

05
PEMBARUAN WEBSITE

Perbarui konten website

Jika ingin mengubah isi website, buka file yang ingin diperbarui di repository, klik ikon edit, lakukan perubahan, lalu pilih Commit changes. Kamu juga dapat mengunggah ulang file yang sudah diperbarui.

GitHub Pages akan menjalankan deployment kembali setelah perubahan masuk ke branch sumber. Buka lagi URL website untuk memeriksa hasil pembaruan. Jika tampilan lama masih muncul, coba muat ulang halaman dengan Ctrl + F5.

CATATAN PENTING

Hal yang perlu diperhatikan.

Website statis

GitHub Pages cocok untuk file HTML, CSS, JavaScript, dan aset statis. GitHub Pages tidak menjalankan backend seperti PHP, Python, atau database secara langsung.

Keamanan informasi

Website yang dipublikasikan dapat diakses melalui internet. Jangan mengunggah password, token API, data pribadi sensitif, atau informasi rahasia ke repository maupun halaman website.
